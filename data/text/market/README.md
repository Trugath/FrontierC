# Commodity names

`strings.tsv` contains 31 authoritative identifier/name pairs in original directory order. `catalog.ini` defines the exact recovered directory range. Display spelling is preserved, including `Fruit and Veg.` and `Gem Stones`. JSON and C includes are generated intermediates.

catalogue system-record commodity columns use these identifiers and this order. Display-text changes can retain identifiers; renaming or reordering an identifier requires updating the corresponding system-record column. Fixed image-size guards remain in effect.
